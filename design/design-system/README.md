# 데모메이커

점이 이어져 별자리가 되기까지. 누군가에게는 꿈, 누군가에게는 이뤄야 할 목표, 누군가에게는 함께 이루고 싶은 것을 눈앞에 보여주고 나누는 서비스의 디자인 시스템입니다.

## 콘셉트: 별자리

| 단계 | 의미 | 서비스 안의 순간 | 시각 은유 | 색 |
|---|---|---|---|---|
| 꿈 | 머릿속에만 있는 생각 | 아이디어 입력, AI 생성 로딩 | 하나의 점(별) | 밤하늘 `night-900`, `violet-700` |
| 목표 | 형태를 갖춰 가는 계획 | 구조 확인, 편집 | 점과 점을 잇는 선 | 새벽빛 `dawn-coral`, `dawn-pink` |
| 함께 | 나누며 커지는 가치 | 배포, 피드백, 다시 다듬기 | 다른 사람의 별이 더해진 별자리 | 아침 바탕 `surface`, 별 `star-gold` |

## 원칙

1. **작업 화면은 아침처럼 밝게.** 에디터, 대시보드, 설정은 `surface` 바탕에 `ink` 글자를 쓴다. 사용자가 만드는 데모가 주인공이고 컨셉은 포인트로만 드러난다.
2. **감정의 순간에만 밤하늘.** 랜딩 히어로, AI 생성 로딩, 배포 완료, 빈 대시보드에서만 `night-900` 배경과 별자리 그래픽을 크게 쓴다.
3. **점은 별, 선은 연결.** 진행 표시, 페이지 지도의 페이지, 피드백 핀은 모두 같은 원형 점(`radius-full`)이다. 페이지 이동 연결과 단계 흐름은 가는 선으로 잇는다.
4. **빛은 아껴 쓴다.** `star-gold`와 `shadow-starlight`는 배포 완료, 새 피드백처럼 무언가가 이뤄진 순간에만 쓴다.

## 색 사용 규칙

- 주요 버튼: `dawn-coral` 배경 + `night-900` 글자. 흰 글자는 대비가 부족하므로 쓰지 않는다.
- 링크와 강조 글자: `dawn-coral-ink`. `dawn-coral`을 글자색으로 쓰지 않는다.
- 밤하늘 위 글자: `ink-on-night`. 보조 글자는 같은 색에 투명도를 주지 말고 `dawn-pink`나 `star-gold`로 위계를 만든다.
- 상태 색 `success`, `danger`는 상태 표시에만 쓰고 컨셉 색과 섞지 않는다.

## 글자

- 글꼴은 **Pretendard** 한 가족, 굵기로 위계를 만든다. Pretendard 파일은 아직 시스템에 포함되지 않아 미리보기에서는 Noto Sans KR로 보일 수 있다.
- `display`는 랜딩 히어로와 배포 완료 화면의 한 문장에만 쓴다. 자간을 살짝 좁혀 단정하게.
- 본문 `body`는 줄간격 26px로 넉넉하게. 한 줄은 40자 안팎을 넘기지 않는다.

## 레이아웃

- 작업 화면: 3단 구조(왼쪽 패널, 가운데 캔버스, 오른쪽 속성 패널). 패널은 `surface-raised` + `line` 테두리.
- 카드: `radius-md`, `space-4` 안쪽 여백, 테두리 + `shadow-card`. 그림자만 단독으로 쓰지 않는다.
- 감성 영역: 가운데 정렬, 위아래 `space-16`.

## 이미지와 아이콘

- 사진 대신 점과 선으로 된 별자리 그래픽을 쓴다. 사람, 마스코트, 풍경 일러스트는 쓰지 않는다.
- 아이콘은 1.5px 가는 선, 끝은 둥글게. 채움 아이콘은 쓰지 않는다.
- 피드백 핀은 `star-gold` 원 + 번호(`caption`, `night-900` 글자).

## 움직임

점이 생기고, 선이 이어지고, 빛이 퍼지는 3단계를 서비스 고유의 움직임으로 쓴다. 각 단계는 200~400ms로 짧게. 작업 화면에서는 움직임을 쓰지 않고, 움직임 줄이기 설정을 켠 사용자에게는 정지 화면을 보여준다.

## 말투

- 감정의 순간에는 "꿈", "함께"를 쓴다. 작업 화면에서는 짧고 정확하게 안내한다.
- "만들어 드릴게요"보다 "같이 만들어 볼까요?"

| 상황 | 문구 |
|---|---|
| 랜딩 히어로 | 당신의 꿈은 어떤 모양인가요? |
| 빈 대시보드 | 아직 그려진 별자리가 없어요. 첫 번째 꿈을 꺼내볼까요? |
| AI 생성 중 | 당신의 생각을 이어 형태를 만들고 있어요 |
| 배포 완료 | 이제 다른 사람들도 당신의 꿈을 볼 수 있어요 |
| 새 피드백 | 3명이 당신의 꿈에 빛을 더했어요 |
| 저장 (작업 화면) | 저장됨 |
